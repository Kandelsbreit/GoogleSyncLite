# Google Drive Sync Lite (Go Edition)

![Google Sync Lite Logo](icon.png)

Легковесная, надежная и сверхбыстрая альтернатива официальному клиенту Google Диск, написанная на **Go** с системным треем, инсталлятором Windows и алгоритмом мгновенной дельта-синхронизации больших библиотек (115 000+ файлов).

---

## Ключевые возможности:

1. **Мгновенная дельта-синхронизация (Fast Delta Engine)**:
   - При повторных синхронизациях локальные файлы сканируются за ~1-2 секунды (проверка `mtime` + `size` против базы данных SQLite).
   - Если файлы не менялись, синхронизация завершается моментально без холостых сетевых запросов к Google Drive.
   - Обрабатываются и выгружаются только новые или измененные файлы.

2. **Режим полного зеркала (Local Master / Mirror)**:
   - Локальный диск является главным источником правды.
   - Полное сохранение иерархии папок и подпапок.
   - Автоматическое удаление из Google Диска файлов и папок, которые были удалены или отсутствуют локально.
   - Защита от дубликатов папок и файлов.

3. **Системный трей Windows (Native System Tray)**:
   - Иконка в области уведомлений Windows (возле часов).
   - Всплывающее контекстное меню по правому клику:
     - 📂 *Открыть интерфейс*
     - 🔄 *Синхронизировать сейчас*
     - ⏹ *Остановить*
     - ❌ *Выход*
   - Сворачивание в трей при закрытии или нажатии «Свернуть в трей».
   - Информативная всплывающая подсказка (Tooltip) с текущим статусом.

4. **Автономность и безопасность (Zero Data Loss)**:
   - Потоковое вычисление контрольных сумм MD5 без избыточного расхода оперативной памяти.
   - Встроенная база SQLite (`sync_state_go.db`) на чистом Go (без CGO / gcc).
   - Самопроверка целостности байт-в-байт (кнопка *«Самопроверка (MD5)»*).

5. **Полноценный установщик Windows**:
   - Скомпилирован через Inno Setup: `GoogleSyncLite_Setup_v1.0.0.exe`.
   - Создает ярлыки на Рабочем столе и в меню Пуск.
   - Опция автозапуска при старте Windows.
   - Чистое удаление через стандартную панель Windows «Установка и удаление программ».

## Установка и запуск

### Вариант 1. Установщик Windows (Рекомендуется)
Скачайте и запустите `GoogleSyncLite_Setup_v1.0.0.exe` из раздела [Releases](https://github.com/Kandelsbreit/GoogleSyncLite/releases).

### Вариант 2. Портативная версия
Скачайте `GoogleSyncLite.exe` и положите рядом ваш файл `credentials.json`. Запустите файл.

## Сборка из исходников:

Требуется Go 1.22+:

```bash
# Генерация иконки и ресурсов Windows
python generate_app_ico.py
rsrc -ico app.ico -o rsrc.syso

# Сборка без консольного окна
go build -ldflags="-H windowsgui" -o GoogleSyncLite.exe .

# Запуск тестов
go test -v .

# Сборка инсталлятора (Inno Setup)
ISCC.exe setup.iss
```
